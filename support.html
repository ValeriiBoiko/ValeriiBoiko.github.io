Getting Help

Before reporting bugs, please make sure you're using the latest version of the app. Updates often include important fixes and performance improvements.

If the issue persists, try reinstalling the app — in many cases, this resolves problems caused by cached data.

We usually respond within 24–48 hours. Thank you for your patience and for using TrainHub!
